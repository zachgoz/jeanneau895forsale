## Performance provenance

Current performance descriptions, profiles and calculator fixtures use all 11 rows from Yamaha’s official September 18, 2016 NC 895/twin F200XCA and LF200XCA bulletin. Former owner observations and the dealer reference are excluded. The **Cruise** profile and description use the published **4,500 RPM / 32.0 MPH / 18.9 combined GPH / 1.69 statute MPG** row. The default remains **4,000 RPM / 26.8 MPH / 14.8 combined GPH / 1.81 published MPG**.

These are model test references, not measurements of EZ Livin. Yamaha reports 159 gallons model fuel capacity and 8,964 lb tested weight; neither replaces seller specifications. Exact rows retain published MPG for display; calculation MPG uses MPH/GPH. Intermediate points are labeled linear estimates, and no values are extrapolated beyond 1,000–5,950 RPM. There is no evidence for sound/dBA data.

The calculator keeps seller **158 gallons**, selected reserves and a distinct zero-reserve theoretical label. Range and trip fixtures use Yamaha values; they are mathematical tests, not tested passages or route-safety guarantees. The owner’s original two-week ICW trip experience remains separate narrative evidence without a first-person performance claim.
